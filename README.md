# Mi Portafolio Docente Digital — Lic. Johan Beltre

Blog educativo estático (HTML). Páginas: `index.html`, `evidencias.html`, `planificaciones.html`, `reflexiones.html`, `perfil.html`.

## Cómo editarlo
1. Abre el sitio y pulsa **✏️ Editar página** (abajo a la derecha).
2. Haz clic en cualquier texto para escribir; haz clic en una foto para cambiarla.
3. Nombre, área y foto de perfil se cambian en todas las páginas a la vez.
4. Para que el cambio sea permanente en internet: **⬇ Descargar página** y sube ese archivo a GitHub (Add file → Upload files).
   También puedes editar directamente en GitHub con el ícono del lápiz.

Foto de perfil: `assets/johan.jpg` (reemplázala por otra con el mismo nombre).
